# Задача 1 - дебаг и доработка системы


## Общее описание разработанной системы

Приложение представляет из себя симуляцию работы одиночного структурного (чистый си) объекта осциллографа.

Основные функции приложения:

0) Симуляция времени
1) Генерация сигнала, через "phase-base генератор" концепцию в виде пачки сэмплов
2) Заполнение основного кольцевого буффера для сэмплов (время чтения + значение) сигналов объекта осциллографа на каждом тике
3) Рантайм анализ буффера (обнаружение рантайм значений mean, median, extrema, amplitude, dc offset; заполнение данных в контекст детектора полуволн) на базе собственного алгоритма на базе частично измененных базовых ЦОС-алгоритмов
4) Медленный анализ буффера (определение measured-значений периода, частоты, амплитуды, экструмумов на базе собственного алгоритма детектора периода / амплитуды.
5) Формирование данных для рендеринга сигнала
6) Рендеринг основного GUI осциллографа (корпус, кнопки, надписи, дисплей во включенном и выключенном состоянии)
7) Рендеринг сигнала и характеристик сигнала в разных режимах развертки (фикс время шага, фикс кол-во периодов)
8) Ограничение частоты выполнения функций в основном цикле приложения  


Реализованные фичи:

1) Детектор периода с концепцией возможности детекции сложных волн (более 2 полуволн в 1 волне)
2) Фиксированная развертка, развертка с фикс. кол-вом периодов
3) Воспроизведение сигнала в виде аудио


По состоянию на момент:

* Приложение с горем пополам работает
* Рендер GUI осца работает суперадекватно и стабильно (как общие вещи, так и всякая динамика типо изменения * рандомайзером цвета дисплея, ореол свечения вокруг дисплеев во включенном состоянии)
* Рендер сигнала работает (но не совсем так клёво, как мог бы)
* Рантайм характеристики вроде бы читаются почти идеально
* Период обнаруживается (но только на чистых или не очень шумных сигналах)
* Развертки в 2 режимах из 3 строятся (но как-то дёрганно и тошнотворно)
* Аудиосигнал выводится и воспроизводится без проблем
