## Старая версия гайдлайна

Неактуализированная версия описания принципа работы приложения лежит в **detection_base/my_approach.md,** но этот файл уже не до конца соответствует действительности, просто был составлен перед работой для того, чтобы понимать, что делать - его новая версия будет второй задачей.


## Общее описание приложения

Приложение работает на внешних SDL2 + SDL_ttf

Основные файлы:

Сама апа - **main.c** + **app.h / app.c**
Мастер-файл движка для вставки - **engine.h**
Симуляция времени - **app_timer.h / app_timer.c**
Генератор сигналов - в **my_generator.c**
Осциллограф довольно-таки захардкоженный, и логика и GUI в 1 файле - **scope.h / scope.c**


Привязан к гиту - https://github.com/dimakomplekt/scope_1.0

Собирается просто через run.ps1


## Описание структуры идеального гайдлайна

Идеальный гайдлайн в общем смысле должен давать полное понимание того, как работает данная система. Соответственно, он должен состоять из общей теории, частной теории и описания практической реализации теории - общий анализ пайплайна работы приложения. Для того, чтобы гайдлайн был интересным надо учитывать психологию людей и всякую там банальную методологию обучения. Первично необходимо формирование понимания того, зачем вообще нужно такое приложение (для чего используются осцилографы), потом формирование понимания того, что примерно необходимо реализовать для того, чтобы получить готовый осциллограф, после этого нужно произвести обзор теории, а затем - обзор работы общего алгоритма и его основных идей (просто копипаст основных функций по пайплайну с комментариями).
